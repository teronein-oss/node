# 학생 성적조회 도트 캐릭터 제작 계획

## 화면 구성

1. 회차별 전체 점수 추이: 막대 아래에 `객관식 + 서술형 = 총점`을 회차별로 표시한다. 서술형이 없는 시험은 `객관식 = 총점`만 표시한다.
2. 회차별 점수 추이·회차별 성적·전체 인원 점수 분포: 해당 회차의 학생 총점에 맞는 응원 캐릭터를 표시한다. 미응시 회차에는 표시하지 않는다.
3. 전체 인원 점수 분포: `100–90`, `89–80`, `79–70`, `69–60`, `59–0`의 다섯 행으로 표시한다. 기존 원본의 `90–99`와 `100`, `0–49`와 `50–59` 비율은 각각 합쳐 보여준다. 학생 위치는 저장된 구간명 대신 실제 총점으로 정한다.

## 적용 테마: 한 마리 병아리의 영어 공부 여정

다섯 구간에서 동일한 노란 병아리의 얼굴·몸·색을 유지하고, 소품과 동작만 점차 발전시킨다. 낮은 점수도 실패나 슬픔이 아닌 시작과 성장으로 표현한다.

| 표시 구간 | 제안 동작 | 응원 문구 |
| --- | --- | --- |
| 59–0 | 작은 연필을 들고 한 걸음 내딛기 | 한 걸음씩 시작해요 |
| 69–60 | 공책을 열고 고개 끄덕이기 | 차근차근 쌓이고 있어요 |
| 79–70 | 단어 카드를 넘기며 가볍게 점프하기 | 좋은 리듬을 찾았어요 |
| 89–80 | 날개를 펴고 높게 점프하기, 작은 반짝임 | 실력이 빛나고 있어요 |
| 100–90 | 두 날개를 들고 별·메달이 반짝이는 세리머니 | 멋지게 해냈어요 |

다섯 구간 모두 같은 병아리를 사용한다. 각 구간의 여섯 프레임을 별도 투명 시트로 제작해 점수 추이·회차별 성적·인원 분포에 적용했다. 100점은 90점대와 같은 상위 구간으로 취급한다.

## 애니메이션 원칙

- 점수 구간당 6프레임 투명 PNG 스프라이트 시트(3열×2행)를 사용한다. 동일한 병아리의 크기·발 기준선을 맞추고 제자리 동작만 바꿔 차트나 표의 위치를 움직이지 않는다.
- GIF나 이미지 여섯 개의 반복 다운로드 대신 시트 한 장을 세 화면 영역에서 재사용한다.
- 32–48px 크기에서도 알아볼 수 있도록 연필·공책·카드·별의 실루엣을 단순하고 큼직하게 만든다. 2–2.4초 간격의 차분한 제자리 반복으로 표시한다.
- `prefers-reduced-motion` 설정 또는 인쇄에서는 움직임을 멈춘다.
- 색상만으로 점수 구간을 전달하지 않고, 점수·구간·응원 문구를 함께 제공한다.
- 캐릭터 이미지가 없어도 성적 조회와 점수 계산은 그대로 작동해야 한다.

## 샘플 확인

가상 학생 코드 `HSE8-C329`(하위 구간), `KMS6-B427`(중위 구간), `LEE7-A526`(상위 구간)로 다섯 점수 구간을 확인할 수 있다. 시험 대분류를 바꾸면 회차별 점수도 달라진다.

# 학생 성적조회 도트 캐릭터 제작 계획

## 화면 구성

1. 회차별 전체 점수 추이: 막대 아래에 `객관식 + 서술형 = 총점`을 회차별로 표시한다. 서술형이 없는 시험은 `객관식 = 총점`만 표시한다.
2. 회차별 점수 추이·회차별 성적·전체 인원 점수 분포: 해당 회차의 학생 총점에 맞는 응원 캐릭터를 표시한다. 미응시 회차에는 표시하지 않는다.
3. 전체 인원 점수 분포: `100–90`, `89–80`, `79–70`, `69–60`, `59–0`의 다섯 행으로 표시한다. 기존 원본의 `90–99`와 `100`, `0–49`와 `50–59` 비율은 각각 합쳐 보여준다. 학생 위치는 저장된 구간명 대신 실제 총점으로 정한다.

## 적용 테마: 알에서 왕관 쓴 닭까지

다섯 구간에서 알이 깨어나 병아리와 어린 닭을 거쳐 왕관 쓴 닭으로 자란다. 같은 노란색 계열과 도트 스타일을 유지하고, 낮은 점수도 실패나 슬픔이 아닌 시작과 성장으로 표현한다.

| 표시 구간 | 제안 동작 | 응원 문구 |
| --- | --- | --- |
| 59–0 | 알이 좌우로 살짝 흔들리기 | 이제 시작이에요 |
| 69–60 | 깨진 알껍데기를 뒤집어쓴 병아리가 몸을 움직이기 | 막 깨어났어요 |
| 79–70 | 병아리가 제자리에서 날갯짓하기 | 날개를 펼쳐요 |
| 89–80 | 볏과 꼬리깃이 자란 어린 닭이 가슴을 펴고 한 발 내딛기 | 훌쩍 자랐어요 |
| 100–90 | 왕관 쓴 닭이 날개를 들고 세리머니하기 | 멋지게 해냈어요 |

각 구간의 여섯 프레임을 별도 투명 시트로 제작해 점수 추이·회차별 성적·인원 분포에 적용했다. 100점은 90점대와 같은 상위 구간으로 취급한다.

## 애니메이션 원칙

- 점수 구간당 6프레임 투명 PNG 스프라이트 시트(3열×2행)를 사용한다. 캐릭터의 크기·바닥 기준선을 맞추고 제자리 동작만 바꿔 차트나 표의 위치를 움직이지 않는다.
- GIF나 이미지 여섯 개의 반복 다운로드 대신 시트 한 장을 세 화면 영역에서 재사용한다.
- 실제 표시 크기는 기본 44px, 좁은 영역 38px이다. 큰 눈·볼과 굵은 도트 외곽선, 단순한 색면으로 알껍데기·날개·볏·꼬리깃·왕관이 작은 화면에서도 보이게 한다. 2–2.4초 간격의 차분한 제자리 반복으로 표시한다.
- `prefers-reduced-motion` 설정 또는 인쇄에서는 움직임을 멈춘다.
- 색상만으로 점수 구간을 전달하지 않고, 점수·구간·응원 문구를 함께 제공한다.
- 캐릭터 이미지가 없어도 성적 조회와 점수 계산은 그대로 작동해야 한다.

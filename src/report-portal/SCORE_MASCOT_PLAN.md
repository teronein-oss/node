# 학생 성적조회 도트 캐릭터 제작 계획

## 화면 구성

1. 회차별 전체 점수 추이: 막대 아래에 `객관식 + 서술형 = 총점`을 회차별로 표시한다. 서술형이 없는 시험은 `객관식 = 총점`만 표시한다.
2. 회차별 점수 추이·회차별 성적·전체 인원 점수 분포: 해당 회차의 학생 총점에 맞는 응원 캐릭터를 표시한다. 미응시 회차에는 표시하지 않는다.
3. 전체 인원 점수 분포: 기존 `0–49점`과 `50–59점` 비율을 더해 `0–59점` 한 행으로 표시한다. 학생 위치도 같은 통합 행에 표시한다. 원본 성적과 분포 데이터는 변경하지 않는다.

## 캐릭터와 응원 문구

| 총점 | 캐릭터 | 문구 | 프레임 동작 |
| --- | --- | --- | --- |
| 0–59 | 병아리 | 한 걸음씩, 좋아! | 웅크림·점프·날개 파닥·착지·눈깜빡임 |
| 60–69 | 새싹 | 조금씩 자라고 있어! | 줄기 성장·잎 흔들림 |
| 70–79 | 토끼 | 좋은 흐름이야! | 귀 쫑긋·가벼운 제자리 점프 |
| 80–89 | 고양이 | 꾸준함이 빛나! | 기지개·꼬리 흔들림·윙크 |
| 90–99 | 여우 | 멋진 집중력이야! | 꼬리 흔들림·별 반짝임 |
| 100 | 별곰 | 완벽한 한 회차! | 두 팔 들기·왕관과 별 반짝임 |

## 애니메이션 원칙

- 점수 구간당 6프레임 투명 PNG 스프라이트 시트(3열×2행)를 사용한다. 프레임은 캐릭터의 제자리 동작만 바꾸고 차트나 표의 위치를 바꾸지 않는다.
- GIF나 이미지 여섯 개의 반복 다운로드 대신 시트 한 장을 세 화면 영역에서 재사용한다.
- `prefers-reduced-motion` 설정 또는 인쇄에서는 움직임을 멈춘다.
- 색상만으로 점수 구간을 전달하지 않고, 점수·구간·응원 문구를 함께 제공한다.
- 캐릭터 이미지가 없어도 성적 조회와 점수 계산은 그대로 작동해야 한다.

## 샘플 확인

가상 학생 코드 `HSE8-C329`(0–59점대), `KMS6-B427`(60–80점대), `LEE7-A526`(90–100점대)로 각 캐릭터를 확인할 수 있다. 시험 대분류를 바꾸면 회차별 점수도 달라진다.

# 학생 성적조회 도트 캐릭터 제작 계획

## 화면 구성

1. 회차별 전체 점수 추이: 막대 아래에 `객관식 + 서술형 = 총점`을 회차별로 표시한다. 서술형이 없는 시험은 `객관식 = 총점`만 표시한다.
2. 회차별 점수 추이·회차별 성적·전체 인원 점수 분포: 해당 회차의 학생 총점에 맞는 응원 캐릭터를 표시한다. 미응시 회차에는 표시하지 않는다.
3. 전체 인원 점수 분포: 기존 `0–49점`과 `50–59점` 비율을 더해 `0–59점` 한 행으로 표시한다. 학생 위치도 같은 통합 행에 표시한다. 원본 성적과 분포 데이터는 변경하지 않는다.

## 애니메이션 원칙

- 제자리에서 4px 이내로 가볍게 움직이는 반복 동작만 사용한다. 차트나 표의 위치를 바꾸지 않는다.
- GIF 대신 투명 PNG 한 장과 CSS 애니메이션을 사용해 용량과 재사용성을 관리한다.
- `prefers-reduced-motion` 설정 또는 인쇄에서는 움직임을 멈춘다.
- 색상만으로 점수 구간을 전달하지 않고, 점수·구간·응원 문구를 함께 제공한다.
- 캐릭터 이미지가 없어도 성적 조회와 점수 계산은 그대로 작동해야 한다.

## 샘플 확인

하위권 가상 학생 코드 `HSE8-C329`로 조회하면 0–59점 회차에서 병아리 샘플을 확인할 수 있다. 다른 점수대 캐릭터는 샘플 승인 후 동일한 표시 규칙에 따라 추가한다.
